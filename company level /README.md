# Tuckit Admin Control Center

Production-grade admin and operations console replica for Tuckit smart IoT physical locker systems.

---

## 📖 Mandatory Agent & Developer Guide

Before developing, modifying code, or running any AI agent tasks on this project, please consult:

- **[Agent Walkthrough & Operations Manual](docs/WALKTHROUGH.md)** — **MANDATORY FIRST STEP** for all AI agents. Outlines project context, operating rules, route map, safety protocols, and full changelog.
- **[Design System Guidelines (DESIGN.md)](../../DESIGN.md)** — Typographic scale, spacing, radii, color tokens, and restraint principles.

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
